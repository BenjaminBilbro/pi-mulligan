# PRP — P1.M2.T1.S4: Filter resolves against pinned hideEntryIds (transforms.ts filterPipeline)

## Goal

**Feature Goal:** Make `filterPipeline` (src/transforms.ts) PIN-AWARE so that a rewind marker carrying a non-empty `hideEntryIds` resolves its removal set from those pinned entry ids (a STABLE target captured at creation by S3) instead of the live per-granularity resolver — closing BUG-002 (a later rewind can no longer retarget an earlier one; originally-hidden content cannot reappear). The pin is resolved CORRECTLY under composition (multiple stacked and mixed pin/live rewinds), not just for a single rewind.

**Deliverable:** (a) MODIFY `filterPipeline` in src/transforms.ts: add a pin dispatch arm (the FIRST arm in the rewinds loop) that, when `readOwn(rw, 'hideEntryIds')` is a non-empty array, resolves the removal set via `mapEntryIdsToMessageIndices(messages, branchEntries, pinned)` and TRANSLATES the resulting ORIGINAL indices to CURRENT `m`-indices through a new parallel `origIdxOfM: number[]` array; add the `origIdxOfM` bookkeeping (`origIdxOfM = applyRewind(origIdxOfM, remove)` in lockstep with `m`). (b) UPDATE the filterPipeline doc-comment: replace the stale `NO hideEntryIds` clause (S1 deferred it to S4) with a description of the pin path. (c) ADD a `describe('filterPipeline — hideEntryIds pin resolution (BUG-002; P1.M2.T1.S4)', ...)` block to test/pipeline.test.ts. No other src or test file is touched.

**Success Definition:** `npx tsc --noEmit` exits 0; `npx vitest run test/pipeline.test.ts` is green (35 existing + new pin tests, including the S1 carry-through test staying green); `npx vitest run` is green (baseline 672 passed/2 skipped + new tests, 0 regressions); a marker WITH non-empty hideEntryIds resolves its removal from the pin (unit test proves pin output differs from live output); TWO STACKED PINS each hide their own target under composition (the BUG-002 unit essence — this test FAILS on the literal contract and PASSES on the corrected approach); a marker WITHOUT hideEntryIds behaves exactly as before; `git diff --name-only` lists EXACTLY src/transforms.ts and test/pipeline.test.ts.

## Why

- **BUG-002 root cause (critical):** `filterPipeline` re-resolves each rewind's target LIVE against the current (already-reduced) message list on every inference (spec D7). For `last_tool_call_group`, when a SECOND rewind marker exists, the FIRST rewind's 'last toolGroup' re-resolves to whatever is now last (often the second rewind's own group, or a newer non-rewound tool call) — NOT the span the agent originally shed. Net: originally-hidden content reappears, violating PRD success criterion #4. S1 shipped the `hideEntryIds?: string[]` field; S2 shipped `mapEntryIdsToMessageIndices`; S3 populates the pin at creation. S4 (this task) is the filter-side CONSUMER that makes the pin authoritative.
- **The work-item contract's literal pin call is INCOHERENT under composition (this PRP's central finding).** The contract says `remove = mapEntryIdsToMessageIndices(m, branchEntries, pinned)` where `m` is the REDUCING array. But `branchEntries` is the FULL branch (getBranch().slice().reverse(), root→leaf — passed by filter.ts:contextHandler, fixed across the loop), so its entry-positions align with `m`'s indices ONLY while `m === messages` (the first rewind). After rewind#1 gap-closes `m`, a later pin's branch-walk yields original-positions that no longer match `m`'s current indices → it removes the WRONG messages. Spike-verified (/tmp/s4-spike.mjs APPROACH A): on the BUG-002 fixture the literal call leaves GREP-OUTPUT visible and mis-removes rewind#2's own toolGroup. The S5 regression test (`includes('GREP-OUTPUT') === false`) would FAIL.
- **The corrected approach (spike-verified APPROACH B):** resolve the pin against the ORIGINAL `messages` (m starts === messages and only diverges after the first removal) via `mapEntryIdsToMessageIndices(messages, branchEntries, pinned)`, then TRANSLATE each original index to its current `m`-index through a parallel `origIdxOfM: number[]` (`origIdxOfM[j] ===` original index of `m[j]`), maintained in lockstep by `applyRewind(origIdxOfM, remove)`. This keeps LIVE resolution byte-for-byte unchanged (still resolves against `m`, returns `m`-indices) → the 672-test baseline is unaffected — and makes composition correct (both toolgroups hidden, both rewind confirmations kept).
- **Backward compat:** `hideEntryIds` is OPTIONAL. Markers WITHOUT it (legacy, capture-failed, or S1's degenerate-fixture test) take the existing live-resolution path unchanged. S1's carry-through test (test/pipeline.test.ts:440-453) stays GREEN (verified CASE4: with branchEntries=[] the pin resolves to [] and the live path also resolves to [], so both no-op → equal).

### The filterPipeline change (src/transforms.ts, lines 819-867)

Replace the rewinds-loop region. BEFORE the loop, add `origIdxOfM`. Inside the loop, add the pin arm as the FIRST
branch and the lockstep `origIdxOfM = applyRewind(origIdxOfM, remove)`. The exact replacement:

```ts
  let m = messages;
  let origIdxOfM = messages.map((_x, i) => i);
  for (const rw of stableSortBySeq(rewinds)) {
    const granularity = readOwn(rw, "granularity");
    const excludeRaw = readOwn(rw, "excludeToolCallId");
    const excludeId = typeof excludeRaw === "string" ? excludeRaw : undefined;
    let remove: number[]; 
    const pinnedRaw = readOwn(rw, "hideEntryIds");
    if (Array.isArray(pinnedRaw) && pinnedRaw.length > 0) {
      const origIdxs = mapEntryIdsToMessageIndices(
        messages, 
        Array.isArray(branchEntries) ? branchEntries : [],
        pinnedRaw,
      );
      remove = [];
      for (const oi of origIdxs) {
        const curIdx = origIdxOfM.indexOf(oi);
        if (curIdx >= 0) remove.push(curIdx);
      }
      remove.sort((a, b) => a - b);
    } else if (granularity === "last_tool_call_group") {
      const units = partitionIntoUnits(m); 
      remove = resolveLastToolCallGroup(units, m, excludeId) ?? [];
    } else if (granularity === "last_turn") {
      remove = resolveLastTurn(
        m,
        readOwn(rw, "options") as { to_previous_prompt?: boolean } | undefined,
        excludeId,
      ).remove;
    } else if (granularity === "checkpoint") {
      const cpRaw = readOwn(rw, "checkpoint");
      const cpName = typeof cpRaw === "string" ? cpRaw : "";
      remove = resolveCheckpoint(m, Array.isArray(branchEntries) ? branchEntries : [], cpName, excludeId)?.remove ?? [];
    } else {
      remove = [];
    }
    if (!protectedOk(m, remove, config)) continue;
    origIdxOfM = applyRewind(origIdxOfM, remove); 
    m = applyRewind(m, remove);
  }
  for (const sh of stableSortBySeq(shrinks)) {
    m = applyShrink(m, sh);
  }
  return m;

```
