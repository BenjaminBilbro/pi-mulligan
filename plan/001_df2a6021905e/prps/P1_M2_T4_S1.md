## Why

- This is the FOURTH and most important correctness surface of Milestone M2 (the pure, zero-Pi, fully unit-tested core). It is THE pairing primitive — spec/06 §2 makes it the load-bearing rule: "Every transform MUST preserve pairing. The primitive that enforces this is partitionIntoUnits." spec/11 §2 Step 3: "This is the most important step; do not proceed until the pairing invariant holds on randomized inputs."
- Downstream: T5 (P1.M2.T5.S1) — `resolveLastToolCallGroup`, `resolveLastTurn`, `resolveCheckpoint` — calls `partitionIntoUnits(messages)` and walks the returned `Unit[]` to pick the target unit (spec/06 §3/§4/§6; spec/06 §12 pseudocode `const units = partitionIntoUnits(m)`). T6 (P1.M2.T6.S1) — `applyRewind`, `applyShrink`, `filterPipeline` — removes unit `indices` from the array so the call AND all its results vanish together. `filterPipeline` (spec/06 §12) partitions ONCE per fire and threads `units` through the rewind loop. Both APPEND to `src/transforms.ts` and REUSE T4's exported `Unit`/`MessageLike` + the hoisted `isRecord`/`readOwn` (exactly how tokens.ts/ledger.ts/notes.ts siblings reuse their S1 helpers).
- Pairing correctness (api_verification.md §6.4): the model API rejects a request containing a `toolCall` without its matching `toolResult` or vice versa. Because removal operates on units, hiding a toolGroup hides the assistant call AND all its results → the filtered view never orphans either side → no API error. This is THE correctness guarantee for all of P1.M2.
- Pure-helper design: transforms.ts is the PERMANENT zero-imports tier (spec/11 §1), like tokens.ts/ledger.ts. It defines its OWN local structural `MessageLike` (a real Pi `AgentMessage[]` assigns in with NO cast — structural typing) and its OWN `isRecord`/`readOwn`. This keeps it Pi-free and unit-testable forever.

### Implementation Patterns & Key Details
```ts
export function partitionIntoUnits(messages: MessageLike[] | null | undefined): Unit[] {
  const list = Array.isArray(messages) ? messages : [];
  const callToAssistant = new Map<string, number>();
  for (let i = 0; i < list.length; i++) {
    const msg = list[i];
    if (!isRecord(msg) || readOwn(msg, "role") !== "assistant") continue;
    const content = readOwn(msg, "content");
    if (!Array.isArray(content)) continue;
    for (const block of content) {
      if (!isRecord(block) || readOwn(block, "type") !== "toolCall") continue;
      const id = readOwn(block, "id");
      if (typeof id === "string" && id.length > 0) callToAssistant.set(id, i);
    }
  }
  const assistantToResults = new Map<number, number[]>();
  for (let i = 0; i < list.length; i++) {
    const msg = list[i];
    if (!isRecord(msg) || readOwn(msg, "role") !== "toolResult") continue;
    const id = readOwn(msg, "toolCallId");
    if (typeof id !== "string" || id.length === 0) continue;
    const assistantIndex = callToAssistant.get(id);
    if (assistantIndex === undefined) continue; 
    let bucket = assistantToResults.get(assistantIndex);
    if (bucket === undefined) { bucket = []; assistantToResults.set(assistantIndex, bucket); }
    bucket.push(i);
  }
  const assigned = new Set<number>();
  const units: Unit[] = [];
  for (const assistantIndex of callToAssistant.values()) {
    if (assigned.has(assistantIndex)) continue;
    const results = assistantToResults.get(assistantIndex) ?? [];
    const indices = [assistantIndex, ...results].sort((a, b) => a - b);
    for (const idx of indices) assigned.add(idx);
    units.push({ indices, kind: "toolGroup" });
  }
  for (let i = 0; i < list.length; i++) {
    if (assigned.has(i)) continue;
    units.push({ indices: [i], kind: "plain" });
  }
  units.sort((a, b) => a.indices[0] - b.indices[0]);
  return units;
}
function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}
function readOwn(obj: unknown, key: string): unknown {
  if (!isRecord(obj)) return undefined;
  try { return obj[key]; } catch { return undefined; }
}
```
