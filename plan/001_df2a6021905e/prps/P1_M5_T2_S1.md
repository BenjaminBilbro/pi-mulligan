## README known-limitation notes (VERBATIM for P1.M5.T4)

The following text is the deliverable for DOCS point 7 ("add known-limitation notes (E7, E18, E15 no GC) to README").

```
### Known limitations
- **Compaction may transiently summarize hidden content (E7).** pi-mulligan hides messages from the model's *view*
  only (the session JSONL is never mutated). Pi's auto-compaction summarizes the oldest messages and may briefly
  reference content mulligan has hidden until the next compaction supersedes that summary. This leak is **bounded and
  transient**. Mitigation: mulligan reduces total context, so compaction fires later and over less material. (A future
  option to strip `mulligan:` references from compaction summaries is deferred — not v1.)
- **Markers persist with no garbage collection (E15).** `mulligan:rewind`, `mulligan:shrink`, and `mulligan:turn-metric`
  entries are permanent (they are the audit trail visible in `/tree`). v1 performs no marker GC and no "squash adjacent
  rewinds." The filter does O(markers × messages) work per inference, which is cheap in practice (few markers; messages
  bounded by compaction), but very long sessions accumulate entries on disk.
- **Nudges are advisory (E18).** The bloated-result reminder and per-turn drift nudge are annotations the model is free
  to ignore. mulligan never forces behavior. If the model disregards them, the only cost is the ~25–40 token nudge when
  it fires (bounded).

```
