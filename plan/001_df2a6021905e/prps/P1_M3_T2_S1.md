# PRP — P1.M3.T2.S1: context handler glue (filter.ts)

## Goal

**Feature Goal:** A `context`-event handler that, on EVERY inference, reads persisted Mulligan markers fresh from the session, delegates all message-list transformation to the pure `filterPipeline`, caches the filtered view in `runtime.lastFiltered` for `mulligan_audit` (P1.M4.T4), and returns `{ messages }`. Fail-open on ANY error (pass-through unchanged). Disabled when `config.enabled === false`. Nudge injection is added in P1.M3.T3 (NOT this task).

**Deliverable:**
- `src/filter.ts` (REPLACE the current `export {};` stub) exporting: `interface MarkersBundle`, `function readMarkers(ctx)`, `function contextHandler(event, ctx)`.
- `test/filter.test.ts` (NEW) — vitest unit suite proving readMarkers + contextHandler via fake-ctx fakes.

**Success Definition:** `npx tsc --noEmit` exits 0; `npx vitest run test/filter.test.ts` green (incl. the F-rewind-core mechanic + F-failopen forced-exception proof via fakes); `pi -e ./src/index.ts -p hi` exits 0 (filter.ts compiles + imports resolve at load); no regression in the existing 411-test suite.

## Why

This is the HEART of Mulligan (spec/03 §1: "a single `context`-event handler reads markers on every inference and rewrites the message copy"). Every rewind/shrink the agent makes is a no-op until this handler wires the persisted marker to the pure pipeline. It is the one Pi-coupled read-path that makes the mechanism take effect on the NEXT inference (C5) and re-apply permanently (C4). Correctness lives entirely in the already-built pure `filterPipeline` (P1.M2.T6) — this task is THIN glue: read markers, call the pipeline, cache, fail-open.

### Implementation Patterns & Key Details
```typescript
export function readMarkers(ctx: ExtensionContext): MarkersBundle {
  const rewinds: RewindMarker[] = [];
  const shrinks: ShrinkMarker[] = [];
  const metrics: TurnMetric[] = [];
  let entries: unknown[];
  try { entries = ctx.sessionManager.getEntries(); } catch { return { rewinds, shrinks, metric: null }; }
  for (const entry of entries) {
    if (!isRecord(entry) || readOwn(entry, "type") !== "custom") continue; 
    const customType = readOwn(entry, "customType");
    if (typeof customType !== "string" || !customType.startsWith("mulligan:")) continue;
    const data = readOwn(entry, "data");
    if (!isRecord(data)) continue; 
    const kind = readOwn(data, "kind");
    if (customType === "mulligan:rewind" && kind === "rewind") rewinds.push(data as unknown as RewindMarker);
    else if (customType === "mulligan:shrink" && kind === "shrink") shrinks.push(data as unknown as ShrinkMarker);
    else if (customType === "mulligan:turn-metric" && kind === "turn-metric") metrics.push(data as unknown as TurnMetric);
  }
  let metric: TurnMetric | null = null;
  let best = -Infinity;
  for (const m of metrics) { const s = readOwn(m, "seq"); const n = typeof s === "number" && Number.isFinite(s) ? s : -Infinity; if (n > best) { best = n; metric = m; } }
  return { rewinds, shrinks, metric };
}
export function contextHandler(event: ContextEvent, ctx: ExtensionContext): ContextEventResult | void {
  let sessionId = "unknown";
  try {
    sessionId = ctx.sessionManager.getSessionId();        
    const config = getConfig();
    if (!config.enabled) return;                           
    const rt = runtime(ctx.sessionManager);               
    const markers = readMarkers(ctx);                      
    const branchEntries = ctx.sessionManager.getBranch().slice().reverse(); 
    const messages = filterPipeline(event.messages, markers, config, branchEntries); 
    rt.lastFiltered = messages;                            
    rt.lastFilterTs = Date.now();
    return { messages: messages as unknown as ContextMessage[] };
  } catch (e) {
    logError("filter.fire", sessionId, { error: e instanceof Error ? e.message : String(e) });
    return;                                               
  }
}

```
