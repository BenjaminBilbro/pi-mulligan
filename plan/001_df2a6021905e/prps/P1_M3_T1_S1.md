## Goal

**Feature Goal:** Ship the ONLY write path from Mulligan's tools/handlers to Pi's session: thin, fail-open wrappers that persist rewind/shrink/turn-metric markers as Pi `CustomEntry`s (NOT in LLM context), the agent's note as a `CustomMessage` (IN context), and checkpoints as Pi `LabelEntry`s. Each wrapper stamps the versioning envelope `{schema:"pi-mulligan",v:1,kind}`, a monotonic per-session `seq` (from runtime.nextSeq, stamped INTO the marker so the filter can order markers deterministically across reload — spec/04 §3, spec/06 §1), and a `ts`. It captures the fresh marker's entry id by calling `ctx.sessionManager.getLeafId()` IMMEDIATELY after `pi.appendEntry(...)` in the same synchronous tick (C7 — appendEntry returns void). Every wrapper is wrapped in try/catch + log and NEVER throws (fail-open: returns null / void on any failure, spec/03 principle #4, spec/08 E13).

## Why

- **Why now / scope:** This is Step 4 of the spec build order (spec/11 §2). The pure-core transforms (P1.M2, ✅) and the runtime map + logger (P1.M1.T3/T4, ✅) already ship. markers.ts is the bridge: it is the ONLY code that calls `pi.appendEntry`/`pi.sendMessage`/`pi.setLabel` (spec/03 §2.1 — "tools never read/transform the message list; they write markers via markers.ts"). Downstream consumers: `tools/rewind.ts` (P1.M4.T1) calls appendRewindMarker + leaveNote; `tools/shrink.ts` (P1.M4.T2) calls appendShrinkMarker; `tools/checkpoint.ts` (P1.M4.T3) calls setCheckpoint; `nudges.ts` turn_end (P1.M3.T3) calls appendTurnMetric. Without markers.ts none of those can persist.
- **The cardinal constraint it encodes (C1/C7/C8/C9):** writes go through `pi` (ExtensionAPI), reads through `ctx.sessionManager` (ReadonlySessionManager — a Pick of read methods only; spec/02 C1). `appendEntry` returns VOID so the leaf id must be captured via `getLeafId()` in the same tick (C7). `sendMessage` from a tool must NOT pass `triggerTurn:true` (mid-turn; C8). Checkpoints are `setLabel` on the leaf (C9). This task makes those constraints concrete and unrepeatable.
- **Boundaries (do NOT cross):** markers.ts is a DUMB persistence layer — it does NOT resolve rewind targets, NOT validate note fields (that's the tool's job, spec/05), NOT read `event.messages`, NOT register handlers/tools, NOT wire into index.ts (P1.M7.T1). It owns the persisted-shape TYPES but IMPORTS the shared payload types (`Granularity`, `NoteInput`, `FileLedger`, `ShrinkTarget`) from their canonical owners (DRY).

## What

A thin TypeScript module. Public functions (signatures are the contract — spec/04 + the work item):

```ts
appendRewindMarker(pi: ExtensionAPI, ctx: ExtensionContext, data: RewindMarkerInput): string | null
appendShrinkMarker (pi: ExtensionAPI, ctx: ExtensionContext, data: ShrinkMarkerInput):  string | null
appendTurnMetric  (pi: ExtensionAPI, ctx: ExtensionContext, data: TurnMetricInput):    string | null
leaveNote         (pi: ExtensionAPI, note: LeaveNoteInput):                           void
setCheckpoint     (pi: ExtensionAPI, ctx: ExtensionContext, name: string):            string | null

```

Behavior per wrapper (appendRewindMarker shown; shrink/turn-metric mirror it):
1. `const rt = runtime(ctx.sessionManager);` — get-or-create the per-session runtime (also yields sessionId for logging).
2. `const seq = nextSeq(rt);` — PRE-increment (first marker this session → seq 1).
3. Build the entry: `{ ...data, schema:"pi-mulligan", v:1, kind:<kind>, id: randomUUID(), seq, ts: Date.now() }` (rewind+shrink stamp `id`; **turn-metric does NOT** — spec/04 §5 has no id field).
4. `pi.appendEntry("mulligan:<kind>", entry);` — appends a `custom` entry (NOT in LLM context). Returns void (C7).
5. `return ctx.sessionManager.getLeafId();` — capture the new leaf id IMMEDIATELY (same synchronous tick, before any other append). NOTE: getLeafId() is typed `string | null`; the return is whatever it returns (null → return null).
6. Whole body in try/catch → `logError("markers.<kind>", sessionId, {error})` → return null. NEVER throws.

`leaveNote(pi, {content, rewindId})`:
1. `const details: NoteDetails = { schema:"pi-mulligan", v:1, kind:"note", rewindId };`
2. `pi.sendMessage({ customType:"mulligan:note", content, display:true, details });` — NO second `options` arg (C8: mid-turn; triggerTurn must stay default false).
3. try/catch → logError("markers.note", "unknown", {error}) (no ctx ⇒ sessionId unknown) → return void. NEVER throws.

`setCheckpoint(pi, ctx, name)`:
1. `const sessionId = ctx.sessionManager.getSessionId();` (for logging; no seq bump — checkpoints are labels, not seq-stamped markers).
2. `const leafId = ctx.sessionManager.getLeafId();` — if `null`, log + return null.
3. `pi.setLabel(leafId, "mulligan:checkpoint:" + name);` — the wrapper ONLY prefixes; name validation (`/^[a-z0-9_-]{1,40}$/`, spec/05 §3) is the checkpoint TOOL's job.
4. return `leafId`. try/catch → logError → return null. NEVER throws.

```ts
export function appendRewindMarker(pi: ExtensionAPI, ctx: ExtensionContext, data: RewindMarkerInput): string | null {
  let sessionId = "unknown";
  try {
    const rt = runtime(ctx.sessionManager);     
    sessionId = rt.sessionId;
    const seq = nextSeq(rt);                      
    const entry: RewindMarker = { ...data, schema: "pi-mulligan", v: 1, kind: "rewind",
                                  id: randomUUID(), seq, ts: Date.now() };
    pi.appendEntry("mulligan:rewind", entry);    
    return ctx.sessionManager.getLeafId();       
  } catch (e) {
    logError("markers.rewind", sessionId, { error: e instanceof Error ? e.message : String(e) });
    return null;                                  
  }
}
export function leaveNote(pi: ExtensionAPI, note: LeaveNoteInput): void {
  try {
    const details: NoteDetails = { schema: "pi-mulligan", v: 1, kind: "note", rewindId: note.rewindId };
    pi.sendMessage({ customType: "mulligan:note", content: note.content, display: true, details });
  } catch (e) {
    logError("markers.note", "unknown", { error: e instanceof Error ? e.message : String(e) });
  }
}
export function setCheckpoint(pi: ExtensionAPI, ctx: ExtensionContext, name: string): string | null {
  let sessionId = "unknown";
  try {
    sessionId = ctx.sessionManager.getSessionId();
    const leafId = ctx.sessionManager.getLeafId();
    if (leafId === null) { logError("markers.checkpoint", sessionId, { error: "no leaf to checkpoint" }); return null; }
    pi.setLabel(leafId, "mulligan:checkpoint:" + name);
    return leafId;
  } catch (e) {
    logError("markers.checkpoint", sessionId, { error: e instanceof Error ? e.message : String(e) });
    return null;
  }
}
```
